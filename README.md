# bridge-defect-inspection
桥梁缺陷智能检测系统

## 项目背景
国内桥梁存量超103万座，31.5%为老旧危桥，传统人工检测效率偏低、成本高昂，细微裂缝极易漏检，高空巡检还存在明显安全隐患。本项目依托深度学习YOLO视觉算法打造桥梁病害智能检测程序，用来替代人工开展巡检作业。

## 技术栈
Python、YOLOv8、OpenCV、PyQt5

## 核心功能
1. 兼容无人机航拍画面、工业摄像头实拍、本地图片三类数据源，自动识别7类桥梁常见缺陷
2. 支持批量完成缺陷筛查，自动汇总检测结果、导出标准化巡检报告
3. 可视化界面方便运维人员查看缺陷位置、统计病害分布情况，辅助基建做智能化养护决策

## 仓库文件说明
- best.pt、yolo系列pt文件：经过训练优化得到的模型权重
- train.py：模型训练脚本，完成数据集训练、参数调优
- 桥梁缺陷检测.pptx、项目代码、成果复盘演示PPT
